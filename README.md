# YouTube Shorts Auto Scroll

YouTube Shorts'ta video bitince otomatik olarak bir sonrakine geçen minimal Chrome eklentisi.

## Kurulum

1. Bu repoyu indir veya klonla.
2. Chrome'da `chrome://extensions` aç.
3. Sağ üstten **Developer mode**'u aç.
4. **Load unpacked** ile bu klasörü seç.
5. `youtube.com/shorts` aç. Sağ alttaki butonla auto scroll'u açıp kapatabilirsin.
