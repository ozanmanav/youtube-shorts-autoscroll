# Changelog

## 1.3.0 - 2026-11-24

- Keeps auto scrolling while the Shorts tab is in the background.
- Detects the end of a Short from the video's own events instead of a timer.
- Background-tab test (`npm run test:background`).

## 1.2.0 - 2026-11-24

- Click the toolbar icon to toggle auto scroll; the badge shows ON or OFF.
- The on/off state stays in sync across all open YouTube tabs.
- Playwright end-to-end test against the real Shorts page, CI checks and issue templates.

## 1.1.0 - 2026-11-24

- Extension icons.
- `Alt + S` keyboard shortcut to toggle auto scroll.
- Auto scroll pauses while the tab is in the background.
- MIT license, release workflow and a full README.

## 1.0.0 - 2026-11-24

- First version: auto scroll to the next Short and an on-page ON/OFF button.
